# Part 1｜Guideline 全文

> 这是 SKILL.md 的完整参考版。SKILL.md 是速查，本文件是权威口径；两者冲突时以本文件为准。
> 附录品牌档案见 `brand-profile-template.md`。

**核心理念**

> **功能是内容，表达是包装。信息直给，句子好读，用户的话，不是工程师的话。**

**定位**：品类级卖点文案规范。适用标题、小标题、一句话卖点（详情页、视频字幕、广告、EDM 主题行）。品牌通用。

## 1. 核心理念与四种失败

| 失败类型 | 表现 |
|---|---|
| **空** | 读完不知道卖什么：*Thrive. / Made for you.* |
| **平** | 像说明书，没人想读：*2.23mm Titanium Smart Ring with 7 Day Battery* |
| **工程味** | 把内部技术词搬上标题：*Bidirectional Adaptive Fit* |
| **学舌** | 照搬竞品，没有自己的卖点 |

**四个拆解测试**

1. 去掉修辞，信息还在吗？（在才合格）
2. 去掉信息，只剩修辞吗？（是就不合格）
3. 换成竞品名字还成立吗？（成立就没差异化）
4. **删掉这个词，用户少知道什么吗？（没少，这个词就该删）**

## 2. 竞品调性：学强项，避同质

> 这是对文案模式的概括，不是原文引用。落地前请对照官网当前文案核实。

| 竞品 | 值得学 | 要避开 | 我们的做法 |
|---|---|---|---|
| **Oura** | 高端、克制；把复杂数据变成一个好懂的概念 | 订阅制；固定尺寸；概念已被它占 | 学命名清晰度；用**无订阅、自适应**拉开 |
| **Ultrahuman** | 自信、动词有力；性能感 | 圈层术语多，普通用户有门槛 | 学语气；把术语翻成日常话 |
| **RingConn** | 数字直白；主打续航和无订阅 | 质感弱，常被当"平替" | 学数字直给；在质感、自适应、健康闭环上拉开 |

**综合要求**：像 Oura 一样清晰有权威，像 Ultrahuman 一样有劲，像 RingConn 一样数字直白，再用自己独有的卖点说出自己的话。

## 3. 从 Insta360、Anker 吸收的 6 个公式

两个品牌的共同点：**标题就是产品说明，但读起来不无聊，也不用工程师的词。**

| # | 公式 | 做法 | 来自 | 智能戒指示例 |
|---|---|---|---|---|
| F1 | **一个数字当主角** | 最硬的参数放最前或最后，只放一个数字 | Insta360（参数即卖点） | *Just 2.23mm Thin* / *7 Days Per Charge* |
| F2 | **一个动作，一个结果** | 用动词直接说用户做什么、得到什么 | Insta360（拍完即得，少操作） | *Wear It. Get Your Recovery Score.* |
| F3 | **痛点 → 解法** | 前半句是麻烦，后半句是功能 | Anker（解决充电焦虑） | *Ring Too Tight at Night? It Adapts.* |
| F4 | **证据贴身** | 卖点后面跟认证、测试或样本 | Anker（认证、测试、质保） | *Tested Against Hospital ECG* |
| F5 | **省掉了什么** | 强调"不用……" | Insta360 / Anker（免操作、免配件） | *No Subscription. No Start Button.* |
| F6 | **新旧对比** | 点出传统做法的短板，再给差异 | Insta360（对比传统设备做不到的事） | *Fixed-Size Rings Squeeze. This One Adapts.* |

> **共同底色**：直白、数字、对比。用户看完，就知道它能做什么、比别的强在哪。

## 4. 标题的信息结构

| 层 | 内容 | 要求 |
|---|---|---|
| ① 功能 / 参数 | 做什么、多少、多久 | **必须有** |
| ② 用户获益 | 对我有什么用 | **必须有**（可放小标题） |
| ③ 证据 / 对比 | 凭什么信 | 加分项 |

- **一个标题只讲一个卖点**
- 主标题 3–8 词；视频字幕 ≤ 7 词；Google 标题 ≤ 30 字符
- 单独成句的部分必须是完整概念（*Ultra-Thin.* 可以，*Titanium.* 不行）
- 重音放句尾，参数或关键功能放最后
- 大声读一遍，卡壳的地方就要改

### 标题与小标题的分工

| 位置 | 作用 | 示例 |
|---|---|---|
| **标题** | 说**是什么**（功能名或最硬的参数） | *Adaptive Fit* |
| **小标题** | 说**怎么做到 / 用户感受到什么**，用动词和日常画面 | *Expands and contracts with your finger.* |
| **一句话卖点** | 标题 + 小标题合并成一句，≤ 12 词 | *Fits as your finger changes through the day.* |

> **小标题不要重复标题**。标题已经说了"Adaptive"，小标题就别再说一遍"adjusts"，要补新信息。

## 5. 说人话：去掉工程师语言

### 5.1 原则

> **用户不是来学技术的，是来买结果的。**
> 工程师描述"它怎么构成"，消费者想知道"它让我怎样"。

文案里的每一个词，都要通过这个问题：**"一个北美普通消费者，在朋友家聊天时会说这个词吗？"**

### 5.2 反例拆解：*Bidirectional Adaptive Fit / Expands and contracts with your finger.*

| 问题 | 分析 |
|---|---|
| **"Bidirectional"** | 这是结构说明（向两个方向伸缩），是工程师想强调的技术点。 |
| **多此一举** | 小标题 *Expands and contracts*（会变大也会变小）已经把"双向"讲完了。标题再写一遍是重复。 |
| **消费者的感受** | 用户不关心"双向"，只关心"我手指胖了瘦了，它都舒服"。 |
| **读起来的效果** | 三个词的标题里，一个词是术语，增加理解成本，没有增加购买理由。 |
| **用上面的测试验证** | 删掉 *Bidirectional*，用户少知道什么？什么都没少。所以删。 |

**修改后**

| 版本 | 标题 | 小标题 |
|---|---|---|
| ❌ 原稿 | Bidirectional Adaptive Fit | Expands and contracts with your finger. |
| ✅ 直白款 | **Adaptive Fit** | Expands and contracts with your finger. |
| ✅ 更口语 | **A Ring That Fits Your Finger, Every Day** | Expands when it swells. Contracts when it shrinks. |
| ✅ 表达款（F3） | **Ring Too Tight at Night? It Adapts.** | Flexes as your finger changes. |
| ✅ 表达款（F6） | **Fixed Rings Squeeze. This One Adapts.** | Expands and contracts with your finger. |

> 注意：*Adaptive Fit* 本身已经是消费者能懂的词。*Expands and contracts with your finger* 是动词加画面，保留。

### 5.3 工程师语言的 6 种常见形态

| # | 形态 | 反例 | 为什么不行 | 改成 |
|---|---|---|---|---|
| 1 | **结构 / 原理词** | Bidirectional / Dual-layer / Multi-axis / Micro-structure | 描述构造，不描述好处 | 删掉，或写用户感受：*Flexes with your finger* |
| 2 | **算法 / 技术名** | Photoplethysmography (PPG) / Algorithm-driven / Sensor fusion | 用户不知道，也不在乎 | *Tracks your heart rate and sleep* |
| 3 | **指标缩写** | SDNN / RMSSD / ICC 0.94 / Δ / SpO₂ 误差范围 | 数据科学家的语言 | 标题用 *HRV* 或 *Recovery*，缩写放脚注或详情页深层 |
| 4 | **内部型号 / 代号** | TC-4 / Gen-3 Sensor / Module B | 对用户没有意义 | *Aerospace-grade titanium*（TC-4 放规格表） |
| 5 | **功能堆砌** | Multi-sensor, multi-metric, multi-mode tracking | 一连串 multi，没有一个具体信息 | 选一个讲：*Tracks 20+ health metrics* |
| 6 | **"Next-Gen / Advanced / Smart / Intelligent"** | Next-Gen Adaptive Fit / Advanced Sensor Technology | 万能修饰，删掉不影响信息 | 删除，或用数字替换：*Just 2.23mm* |

### 5.4 词汇分级表（智能戒指品类）

| 级别 | 规则 | 例子 |
|---|---|---|
| 🟢 **可直接用** | 北美消费者日常能懂 | Sleep / Recovery / Heart Rate / Battery / Waterproof 类词 / Titanium / Fit / Size / Workout / Stress |
| 🟡 **需配一句人话解释** | 品类用户（买过 Oura 的人）懂，新用户未必懂 | HRV（*Heart Rate Variability, a sign of recovery*） / SpO₂（*Blood Oxygen* 更好） / Readiness / Baseline / ATM 等级（*5ATM: swim-ready*） |
| 🔴 **不上标题** | 工程师或研究者语言 | Bidirectional / PPG / SDNN / RMSSD / ICC / Sampling rate / Algorithm / Sensor fusion / Photodiode / Biofeedback loop / Resilience coefficient |

**使用规则**

- 🟡 词在同一页面**首次出现时**配解释，之后可直接用
- 标题优先用更口语的版本：*Blood Oxygen* 优于 *SpO₂*，*Heart Rate Trends* 优于 *HRV Index*
- 🔴 词只能出现在规格表、白皮书、研究摘要
- 对内沟通中的术语（比如"双向伸缩结构"），对外要先**翻译成用户能感受到的效果**，再写

### 5.5 翻译公式：工程师语言 → 消费者语言

> **结构 / 原理 → 用户感受 → 一个画面**

| 工程师说 | 用户感受 | 文案 |
|---|---|---|
| 双向伸缩结构 | 手指胖瘦都舒服 | *Fits as your finger changes* |
| 钛合金 TC-4，2.23mm | 轻，戴着没感觉 | *Barely there. 2.23mm titanium.* |
| HRV RMSSD 短期恢复 + SDNN 长期适应力 | 今天累不累，长期在变好还是变差 | *Today's recovery. Your long-term trend.* |
| PPG 连续血氧采样 | 睡眠中的血氧变化 | *Blood oxygen, tracked all night* |
| 基于个人基线的 AI 模型 | 说的是"我"的情况 | *Insights based on your own data* |
| HRV 生物反馈呼吸 | 一边呼吸，一边看到心脏放松 | *Guided breathing. Watch your heart respond.* |
| 5ATM | 能游泳、洗澡 | *Swim, shower, sweat.* |

## 6. 智能戒指卖点库与默认顺序

| 层 | 卖点 |
|---|---|
| **愿意戴** | 自适应 / 尺码 → 超薄、轻、钛合金 → 珠宝感外观 |
| **需要戴** | 每日恢复 → 长期趋势 → AI 解读 → 引导呼吸 |
| **能证明** | 睡眠 / 血氧 / 呼吸 → 自动运动 → 女性周期 → 精度证据 |
| **放心买** | 续航 + 充电盒 → 防水 → 无订阅 → iOS + Android |

每个品牌只写自己真正有的卖点，没有的不写。

## 7. 渠道规则

| 渠道 | 要求 |
|---|---|
| **视频字幕** | 主标题 ≤ 7 词，小标题 ≤ 10 词；每屏 ≥ 1.5 秒；不遮挡 UI；转场 / 旋转镜头只放一行或不放；生活镜头每个讲一个不同功能 |
| **详情页 H1** | 品类 + 参数 + 最强差异 |
| **详情页 H2 + 小标题** | H2 讲功能名，小标题讲用户感受，用动词 |
| **Meta / TikTok** | 前 3 秒用 F3 或 F6 |
| **Google 搜索** | 关键词 + 参数，每条 ≤ 30 字符 |
| **EDM 主题行** | 一个数字或一个对比，≤ 50 字符 |
| **落版** | 品牌名 + 一行功能型，不用情绪口号 |

## 9. 禁用与慎用

### 9.1 禁用词与句型

**A. 抽象品牌词：没有任何功能信息**

| 禁用 | 为什么不行 | 改成 |
|---|---|---|
| Thrive / Flourish | 不知道产品做了什么 | 直接写功能结果：*Recovery Score Every Morning* |
| Journey / Path to wellness | 空泛，每个健康品牌都在用 | *Track Long-Term Trends* |
| Elevate / Redefine / Reimagine | 万能动词，换谁都成立 | 具体动词：*Track / Measure / Adapt* |
| Unleash / Unlock your potential | 夸大，无法验证 | *See How Your Body Recovers* |
| Moments / Rhythm / Harmony / Balance（单独使用） | 意境词，没有信息 | 写具体指标：*Sleep / Recovery / Stress* |
| Next level / Beyond | 空洞比较级 | 写比什么强：*Thinner than a [X]* |
| Wellness companion / Health partner（作主标题） | 品牌口号 | 写功能：*Adaptive Smart Ring* |

**B. 万能句：谁都能说**

| 禁用 | 改成 |
|---|---|
| Brings It All Together | 写具体"together"了什么：*Sleep, Heart Rate and Activity in One Score* |
| Made for you / Designed around you | *Adapts as Your Finger Changes* |
| Fits You. Gets You. | *Fits at 7 AM. Still Fits at 7 PM.* |
| Your health, your way | *Choose 6 Sizes. No Subscription.* |
| Smarter living / Live better | 写哪方面更好：*Know When to Rest* |
| Everything you need | 列出 2–3 个具体功能 |
| Feel the difference | 给一个可对比的数字 |

**C. 自造术语作主标题**

| 禁用 | 原因 | 改成 |
|---|---|---|
| Liquid Light Finish | 用户看不懂 | *Mirror-Polished Titanium* |
| Bio-Resonance / Vital Flow 类词 | 像伪科学 | 写真实功能名 |
| 自造缩写、内部产品代号 | 用户不认识 | 写通用名 |

> 自造术语可以放在详情页深层或规格表，不能当主标题。

**D. 工程师语言（详见第 5 节）**

| 禁用（标题 / 小标题 / 一句话卖点） | 改成 |
|---|---|
| **Bidirectional** Adaptive Fit | *Adaptive Fit* |
| Dual-sensor / Multi-sensor / Multi-axis | 写它能测什么：*Tracks heart rate, blood oxygen and temperature* |
| PPG / Photoplethysmography | *Tracks your heart rate and sleep* |
| SDNN / RMSSD / ICC | *HRV* 或 *Recovery*（缩写放详情页深层） |
| Algorithm-driven / Data-driven / Powered by AI（不说做什么） | *AI Insights Based on Your Own Data* |
| Sensor fusion / Signal processing | 删除，写结果 |
| Next-Gen / Advanced / Cutting-edge / State-of-the-art | 删除，或写数字 |
| Proprietary / Patented technology（作主标题） | 写技术带来的好处，专利号放页脚 |
| Biofeedback（单独使用） | *Guided breathing. Watch your heart respond.* |
| Body resilience coefficient 类自造指标名 | *Long-Term Recovery Trend* |

**E. 翻译腔与中式英语**

| 禁用 | 问题 | 改成 |
|---|---|---|
| Light, Shaped Into a Ring | 直译诗意中文 | *A Ring That Looks Like Jewelry* |
| Every Side of You | 北美不这么说 | 写具体场景 |
| Comfort That Moves With You | 容易被理解成运动追踪 | *Adapts as Your Finger Changes* |
| Accompany your every day | 中文"陪伴"的直译 | *Wear It Day and Night* |
| Take care of your body well | 中式祈使句 | *Track Sleep, Recovery and Stress* |
| Perfect combination of A and B | 套话 | 直接并列 A 和 B |
| Very / So / Super 叠加（*very very thin*） | 口语堆砌 | 用数字：*2.23mm* |

**F. 好听但空的口号**

| 禁用 | 改成 |
|---|---|
| Stress hits. Breathe. | *5-Minute Guided Breathing. Watch Your Heart Respond.* |
| Less data. More answers. | *Health Insights Based on Your Own Data* |
| Wake up to your score. | *Check Your Recovery Score Every Morning* |
| Game on. | *See What That Match Did to Your Recovery* |
| Lap after lap. | *Swim, Shower, Sweat. 5ATM.* |

> 判断标准：好听、有节奏，但去掉修辞后只剩情绪。

### 9.2 慎用词：需要证据、确认或法务审核

**A. 绝对化与第一类用语**

| 慎用 | 规则 | 可替换 |
|---|---|---|
| World's thinnest / smallest / lightest | 必须有第三方对比依据、范围和日期 | *Ultra-Thin at 2.23mm* |
| First / Only / Never before | 必须能证明，且注明范围 | 有依据时再用，并写明范围 |
| Best / #1 / Most accurate | 需要独立评测或销量数据 | 用数据代替：*Tested on 270 participants* |
| Perfect / Flawless / 100% | 几乎无法证明 | 删除，或写具体数值 |
| Always / Never / Guaranteed | 绝对化承诺 | *Designed to…* |
| Revolutionary / Breakthrough | 夸大 | 写具体新在哪里 |

**B. 医疗与诊断类**

| 慎用 | 规则 | 可替换 |
|---|---|---|
| Clinical-grade / Medical-grade | 不用，除非有相应认证 | *Checked against hospital ECG*（注明样本） |
| Diagnose / Detect disease / Treat | 不用 | *Insights / Trends / Awareness* |
| Sleep apnea detection | 不用 | *Nighttime breathing insights* |
| Heart health / Cardiac | 慎用，易被理解为医疗宣称 | *Heart rate and HRV trends* |
| Blood pressure | 只说趋势 | *Blood pressure trends* |
| Fertility / Ovulation prediction | 不宣传"准确预测" | *Cycle insights* |
| Cure / Prevent / Reduce risk of | 不用 | 删除 |
| Stress relief / Anxiety reduction（作疗效） | 避免疗效承诺 | *Guided breathing* |
| FDA / CE 相关字样 | 无认证不得出现 | 删除 |

**C. 技术与功能宣称**

| 慎用 | 规则 | 可替换 |
|---|---|---|
| Real-time / Live | 须研发确认刷新频率和延迟 | 确认前用 *Guided breathing* 等描述 |
| Every second | 只能用于确实每秒更新的指标（如睡眠血氧） | *Overnight Blood Oxygen, Updated Every Second* |
| 24/7 | 需说明充电和摘戴期间的例外 | *All-Day and Overnight Tracking* |
| Accurate / Precise | 要有数据支撑 | 附上经确认的数据 |
| AI-powered | 需有真实 AI 功能，不夸大 | *AI Insights*（具体说做什么） |
| Waterproof | 不准确 | *5ATM Water Resistant* |
| Unbreakable / Scratchproof | 绝对化 | *Titanium Strength* |
| Hypoallergenic | 需要材质认证 | 删除，或写材质名 |

**D. 数字与参数**

| 慎用 | 规则 |
|---|---|
| 厚度、重量、续航 | 全部使用统一口径，不得出现 2.2 / 2.23 / 2.3 混用 |
| 续航 | 必须写 *up to*，并注明测试条件 |
| 总续航（含充电盒） | 注明计算方式 |
| 指标数量（20+ / 30+） | 全品牌统一一个口径 |
| 样本数、ICC、准确率 | 须经法务和研究方确认，并保留原始报告；**标题里不放 ICC 等统计词，只说结论** |
| 价格、折扣 | 必须与页面实际价格一致 |

**E. 竞品对比**

| 慎用 | 规则 |
|---|---|
| 点名竞品 | 只对比事实：订阅费、固定尺寸、指标种类，并保留来源与日期 |
| *Better than Oura / Unlike Oura* | 须有可验证依据；更稳妥是 *Unlike subscription rings* |
| 竞品订阅价格 | 引用前核对当前官网价格 |
| 贬低性措辞（*Sucks / Fails / Outdated*） | 不用 |
| 暗示竞品功能缺失 | 必须核实对方当前功能 |

**F. 用户证言与奖项**

| 慎用 | 规则 |
|---|---|
| Loved by / Trusted by [N] users | 数字需有来源 |
| 评分、星级 | 来自真实平台，注明来源 |
| Award-winning | 须写明奖项名称和年份 |
| 名人 / 专家背书 | 需授权 |

**G. 区域与平台合规**

| 慎用 | 规则 |
|---|---|
