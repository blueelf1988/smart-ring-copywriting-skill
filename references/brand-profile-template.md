# 品牌档案模板（对接新品牌时填写）

> 本文件是公开版模板，示例均为演示值。真实品牌的口径、未确认数据、法务状态请放在团队内部副本里，不要写进公开仓库。
> 用法：复制本文件 → 逐项填写 → AI 写文案时以此为准。**档案里标"待确认"的项不得进入最终文案。**

## A1 数据口径表

所有对外数字必须来自这张表。同一指标只允许一个口径，不允许 2.2 / 2.23 / 2.3 混用。

| 项目 | 口径（内部） | 对外写法 | 状态 |
|---|---|---|---|
| 厚度 | [X.XX] mm（宽 [X.X] mm） | *[X.XX]mm* | ✅ 统一用 [X.XX]mm |
| 材质 | [材质名称 + 牌号] | *[对外材质词]*（牌号只放规格表） | ✅ |
| 尺码 | [N] 个，相邻重叠 [X] mm | *[N] sizes* | ✅ |
| 自适应 | [内部结构叫法] | *Adaptive Fit*（对外不写结构词） | ✅ |
| 续航（戒指） | 最长 [N] 天 | *Up to [N] days* | ✅ 写 up to + 测试条件 |
| 充电盒 | 额外 [N] 次；共约 [N] 天 | *More power in the case* | ⚠️ 需研发确认计算方式 |
| 防水 | [N]ATM | *[N]ATM water resistant* | ✅ |
| 血氧 | [采样口径] | *Overnight blood oxygen* | ✅ |
| 健康指标数 | [一个口径：20+ 或 30+] | *[N]+ health metrics* | ❌ 待统一，统一前不对外 |
| 精度证据 | [样本数、对比方法] | *Checked against hospital ECG*（统计数字放研究摘要） | ⚠️ 需法务和研发确认 |
| HRV | [短期指标 + 长期指标] | *Daily recovery + long-term trends* | ✅ |
| 订阅 | [订阅政策] | *$0 a month* | ✅ |
| 平台 | [iOS / Android] | *iPhone and Android* | ✅ |
| 配色数量 | [N] | *[N] Colors* | ❌ 待确认 |

状态图例：✅ 可直接用｜⚠️ 需研发 / 法务二次确认｜❌ 口径未定，禁止对外。

## A2 差异化支点（对每个主要竞品）

每个支点只写"是什么差异、对谁成立、对方现状如何"。标"核实"的项，对外对比前先查对方官网当前功能与政策。

| 支点 | 对 [竞品 1] | 对 [竞品 2] | 对 [竞品 3] |
|---|---|---|---|
| [支点 1，如：自适应伸缩 + N 尺码] | 成立（对方：固定尺寸） | 成立 | 成立 |
| [支点 2，如：超薄 + 珠宝感] | 成立 | 成立 | 成立（质感差异） |
| [支点 3，如：无订阅] | 强差异 | 核实对方当前政策 | 同类，不作差异点 |
| [支点 4，如：引导呼吸] | 成立 | 核实 | 成立 |
| [支点 5，如：短期恢复 + 长期趋势] | 成立 | 核实 | 成立 |

填写规则：

- 对方也有的，不叫差异点
- 对方的政策 / 功能可能已变化，对外引用前必须核对官网并记录日期
- 贬低性措辞一律不用（见 guideline.md 9.2E）

填写时注意：
